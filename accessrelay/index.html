AccessRelay
Manifest · Network · Policy pack v1 · FormLab
Portable agent network · browser native

Accessibility guidance that travels between websites.

This origin publishes a declarative agent network. With explicit consent, another agentic website can load its instructions into the visitor's own browser — without sending the visitor's AI key or form data to this host.

What the peer can do

  • Explain associated form labels, assistive error messages and contrast.
  • Suggest small allowlisted repairs and a way to verify them.
  • Return general guidance without receiving personal form values.

Boundary: this peer cannot edit FormLab's DOM or execute its site actions. The caller's local runtime performs those actions with user confirmation.

Local P770/P771 QA demonstrated a real LLM answering across origins with separate Apply and Undo approval. This public static site does not supply free hosted inference; the zero-key policy check is deterministic and read-only until you approve a local fix. Neither flow constitutes a WCAG certification.

Public, inspectable rule pack: accessibility-policy-v1.json, revision 2026-11-18.1. It contains three narrowly scoped WCAG-related checks and is pinned by SHA-256 on FormLab. W3C is the standard publisher, not the publisher or endorser of this demo rule pack.
