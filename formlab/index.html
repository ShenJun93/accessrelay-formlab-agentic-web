Try the zero-key proof first

This walkthrough does not call a language model, require a key or submit your form values.

  1. Go to the independent policy section. Keep Email label selected, click Check external policy (no LLM), review the AccessRelay origin and allow one public read.
  2. Read the pinned policy result and preview. Click Apply previewed fix, then approve the browser-local change.
  3. Confirm that the form improved, click Undo last fix and approve again. Export the self-attested JSON receipt if offered.

The optional AI-to-AI assessment uses a real model only when you configure a supported provider. No inference is silently simulated; this is not a WCAG certification.
